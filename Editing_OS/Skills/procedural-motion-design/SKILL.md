# Reference styling and procedural motion design

Owned adaptation of [cth9191/animate](https://github.com/cth9191/animate/tree/7e5eb56feb2dd573f890e1b7b34748af43d58263),
inspected remotely on 2026-10-14. No vendor repository, executable, drawing kit,
demo, font or media was installed. This recipe adds design guidance and a local
observation helper, not an alternative renderer or automatic style recognizer.

Load [Master Prompt](<../MASTER_PROMPT.md>), [Taste Profile](<../TASTE_PROFILE.md>),
[Tool Routing](<../TOOL_ROUTING.md>), [Quality Standard](<../QUALITY_STANDARD.md>)
and applicable handbook Chapter 23 methods. Production retains the five live
authority hashes, validated contracts and owned Orchestration Adapter. Reuse
valid decisions; an OS upgrade does not authorize changing an active film.

Choose story structure by viewer task, medium by explicit reference/taste and
runtime by actual capability. A genre, catalog entry or repository style name
does not select treatment. The [Style Library](<../STYLE_LIBRARY.md>) records
generic unapproved treatment examples; the seven upstream media are design vocabularies, not
seven installed or approved style packages. Reuse actual approved treatment decisions for an applicable job; do not silently reskin it as isometric
line art or generic illustration.

## Common design-to-production contract

1. Inspect the reference's intended artwork region, actual source timestamps,
   geometry and rights. Separate wrappers, compression, camera movement and
   stylistic frame stepping. Derive a small set of structural identity rules;
   do not reduce a look to a palette or copy the reference's story/assets.
2. Plan meaningful scenes in `editorial-intent/v1`. Record identity observations,
   shot context, triggers, state changes, holds, dependency limits and revisions
   in the existing job decision/style artifact. Do not add fields to strict
   production schemas or invent adapter/evidence capabilities.
3. Show 2–3 useful directions when unresolved on the same real material, including
   the hardest action, dense typography and a transition. Match subject framing,
   geometry/materials, lighting, type and motion; then freeze the explicit choice
   in existing `taste-selection/v1`. Draft style records may exist before approval;
   they must not be promoted as approved library styles without a real choice.
4. Build through verified existing HyperFrames/runtime interfaces with local
   assets/fonts, finite durations and frame-indexed or analytic state. Spoken
   activations keep corrected forced alignment and approved `retimed_words`.
   Music reaction follows the actual placed track, never a guessed BPM.
5. Review identity on encoded pixels, moving phases and every requested format.
   Actual graphics/caption/audio QA, full decode, determinism policy and exact-hash
   human playback/device review remain mandatory before publication authority.

The local `Editing_OS/Tools/editing-workbench/style_inspect.py` supplies image ROI,
alpha policy, palette buckets, relative-luminance observations and optional
declared subject proportions. It does not infer semantics, fonts, line weight,
camera lens, material parameters, motion cadence, artistic quality or similarity.
See STYLE_IDENTITY for commands and measurement limits.

An upstream `window.renderFrame`, single-canvas build, synthesized soundtrack,
raw faster-whisper timing or vendor review score does not replace current
runtime/timing/audio/readiness. Animate's ray-marched WebGL motion style is
explicitly planned upstream; this integration does not claim to ship it. Real
3D is routed to the existing verified local Three.js/HyperFrames capability.
Changes to Tool Routing change a governing hash: resumed production must run
live preflight and refresh/reapprove affected records rather than rewriting
old approvals. Source coverage and checks live in the
[public source and scope notes](../PROVENANCE.md).
