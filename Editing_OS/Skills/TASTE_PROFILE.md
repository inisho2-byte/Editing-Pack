# Taste Profile — customizable template

This document defines a reusable decision procedure. It contains no personal taste history and grants no treatment or publication approval. Read it before proposing a look. Each job stores its private preferences and decisions in its external workspace; do not accumulate real approval logs in the toolkit.

## Start from the material

Read the objective, audience, footage, emotional intent, accessibility needs, delivery constraints and authorized references. A genre label does not choose palette, font, grade, captions, music, motion or layout. Preserve explicitly approved job choices when still applicable; identify conflicts and invalidated evidence.

## Fill in the job profile

Record the following in the job brief: desired effect; permitted references; choices to preserve; preferences to avoid; caption mode and readability needs; motion intensity; grade intent; audio/music role; output platform; review requirements. Unspecified fields remain unresolved rather than silently becoming a house preset. Do not put names, source footage or private decisions into this template.

## Show and select

When treatment is unresolved, show 2–3 useful alternatives on real material, including a dense scene and a transition/layout example where applicable. Explain tradeoffs. Record the user's explicit choice in taste-selection/v1 with the exact required treatment tokens and evidence. A placeholder, sample JSON, test reviewer or silence cannot supply approval.

Favor a clear hierarchy and adequate reading time while evaluating alternatives; these craft principles do not prescribe a universal aesthetic. Accessibility requirements and the user's selected look determine the actual rendering choices. Captions, overlays and explanatory graphics have separate roles and should not compete for the same focal region.

## Preserve evidence

Hash the current governing template with the other four documents when creating production context. Store the private selected treatment and its artifacts in the job workspace. Any local edit to this governing document changes its hash and requires a new context and revalidation of dependent authority. No history from another user or project is inherited.

## Reference and3D treatment choices

The generic STYLE_LIBRARY and starter materials are unapproved examples. Compare shape, light, camera, materials, typography and motion against the actual reference/content. When unresolved, show useful options on the same material and freeze the explicit choice. Select capture mode deliberately; a renderer/backend label is not a visual or determinism pass. Never publish personal style history as reusable defaults.
