## Make an object communicate

Reserve text/subject safe areas before framing the object. Give each action a clear initial state, intentional path, contact/activation moment, settled reading hold and exit. Keep hinges within a readable angle; separate a card's lift/rotation from its descent into a slot so it does not intersect solid panels. Camera motion follows the viewer's relevant subject, not an unrelated animation clock. Clear type and proof before increasing blur or depth effects.

Resolve geometric form, material response, lighting, camera, typography and motion on the same reference/material before scaling to many scenes. The supplied warm-neutral stage and yellow folder are only draft tokens. Show alternatives when appearance is unresolved and freeze the explicit choice in taste-selection/v1. Generated stills require coherent shot context and reference/state continuity; crossfades cannot repair inconsistent object geometry or camera placement.

## Runtime and ownership

Use explicitly configured local Three.js core/addons, GSAP, fonts, Node and browser. No CDN, automatic npx install, private job asset or installed vendor clone is a dependency shortcut. See [OPS](OPS.md) and installation for the tested resource profile. Website Fiber/Drei/Theatre, glTF optimization, imported animation and additional shaders remain conditional until their actual runtime and rights are verified.

Each scene registers one paused timeline under its composition ID. wireBeat uses hf-seek as the canvas pose owner, subtracts the live host data-start, clamps local time and replaces old same-ID listeners. renderAt is a pure function of absolute local time: no wall clock, accumulated delta, unseeded randomness or autoplay animation. Imported clips require authored/baked absolute poses under the same clock.

Readiness waits for required images/textures/fonts and warm rendering; failure must reject the authoritative promise. Albedo/emissive textures use sRGB; data maps use no color conversion. Printed canvas text is redrawn after required fonts resolve. Material choices such as transmission and alpha testing need actual pixel review, not a generic score. createStage.dispose releases its stage-owned resources; caller meshes and shared MAT remain caller-owned. Clone shared materials for variants and dispose caller-owned derivatives explicitly.

## Verification and publication

Run the required 3D-browser profile for stage dimensions, live host offsets, lifecycle cleanup, nonblank canvas, dependency rejection, A-B-A and shuffled seeking. Check meaningful moving and settled frames in each delivery geometry, actual framework mounting, full encoded decode and independent repeats. Select software/hardware capture explicitly: GPU throughput is not determinism proof. Retain mismatch/cost evidence; do not invent a waiver. Full-size feature support requires a full-size check.

Production speech uses genuine forced alignment, reviewed/hash-bound cuts and retimed words. Intent, treatment, graphics/audio/caption evidence, encoded Quality and exact-artifact human playback review remain the existing production gates. Synthetic draft examples never create human selection or publication approval.
