## Defaults deliberately replaced

Accumulated delta/clock/physics → authored absolute poses or baked frame data.
Autoplay/scroll/damped controls → frozen capture with one output clock.
Network presets/remote fonts/CDN decoders → verified local asset readiness.
AAA game art quotas/HUD → purpose-led focal scene and actual measured budget.
Automatic product/category look → observed reference identity and explicit taste.
Web UI text/timing → platform-specific video type, semantic anchors and holds.
Vendor release/pixel score → evidence with declared scope; encoded Quality and
exact-hash human review remain mandatory. No Blender capability is introduced.
