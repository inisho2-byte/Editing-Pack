# Owned studio object starter

Draft source only. The supplied materials, stage and typography are editable example tokens, not a human-approved look. The folder/card rigs are procedural shapes; no presenter, screenshot, model file, soundtrack or reference image is bundled.

Configure explicit external Three.js0.185.0 core/addons, GSAP3.15.0, Inter400/700 fonts, Node, Puppeteer and browser before running the 3D profile. Installation and the generic demo will stage verified runtime copies with notices/hashes into an external job; source helpers never install or fetch resources during rendering.

studio3d.js exposes createStage, makeFolder, makeCard, reprint, material primitives, pure timing functions, hostStart, wireBeat and required image/texture loaders. stage.css supplies draft layout tokens. beat-template.html is a sub-composition source; examples are original generic scenes with local clock values. Mount through the existing HyperFrames template/importmap contract, using local files and matching host/inner/timeline IDs.

Only hf-seek owns canvas poses. Font/image readiness must resolve before capture and reject failures. Keep caller/shared resource disposal distinct. Verify geometry, forward/backward/random seeks, nonblank frames, live offsets, same-ID replacement and full encoded repeats. All example timestamps are synthetic local-clock demonstrations; production speech must use evidenced post-cut words and genuine approvals.
